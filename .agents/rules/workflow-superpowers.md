# Superpowers Workflow & Skills Discovery Rules

## 1. 100% Superpowers Process Compliance
Whenever executing a process guided by Superpowers (e.g. `brainstorming`, `writing-plans`, `executing-plans`, `subagent-driven-development`, `test-driven-development`, `requesting-code-review`, `verification-before-completion`):
- **Never skip or truncate steps**: Follow 100% of the prescribed phases (Brainstorming/Spec -> Implementation Plan with User Review Checkpoints -> Incremental TDD Execution -> Full Verification).
- **Clear Review Checkpoints**: Do not proceed from planning to implementation without explicit plan review and approval when required.

## 2. Skill-Driven Context & Architecture Discovery
Before designing, brainstorming, or writing code:
- Search and consult relevant skills in `.agents/skills/` (e.g. `swiftui-patterns`, `swiftui-layout-components`, `swiftui-animation`, `swift-architecture`, `swift-concurrency`, `swiftdata`, `ios-design-guidelines`, `swift-testing`, `swiftlint`).
- Ground decisions in modern Apple & project best practices provided in those skills.
