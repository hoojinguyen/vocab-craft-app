# AI Voice Roleplay Experience Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix Speaking AI voice call navigation dismiss freeze, resolve speech recognition audio session race conditions with live decibel metering visual feedback on CraftVoiceOrbView, and implement a dynamic conversational scaffolding system (suggested responses with TTS preview).

**Architecture:** 
- In-View Navigation: `RoleplayVoiceCallView` replaces nested `.fullScreenCover` modal presentation with an inline view transition to `RoleplaySummaryView`, with distinct Close (`X`) discard-alert flow and Hang-Up session-summary flow.
- Audio Pipeline: `SpeechRecognitionService` awaits `.speechCapture` lease acquisition before starting `AVAudioEngine`, computes real-time RMS power (`0.0...1.0`), and drives `CraftVoiceOrbView`'s dynamic pulsing scale.
- Scaffolding: `RoleplayTurnOutput` is extended with `suggestedResponses: [String]`, generated by Gemini/IntelligentMock, and presented in an expandable UI pill with TTS pronunciation preview.

**Tech Stack:** Swift 6, SwiftUI, AVFoundation, Speech framework, Observation, CraftUIKit, SpeechKit.

**Spec:** `docs/superpowers/specs/2026-09-28-ai-voice-roleplay-experience-remediation-design.md`

## Global Constraints

- 0 compiler warnings, 0 SwiftLint warnings.
- 100% test pass rate across all test targets.
- 100% localization parity (both `en` and `vi` translations provided with matching format specifiers) under `app.ai_assistant.*` taxonomy.
- Strict CraftUIKit design token conformance (no raw colors, no hardcoded font sizes or spacing).
