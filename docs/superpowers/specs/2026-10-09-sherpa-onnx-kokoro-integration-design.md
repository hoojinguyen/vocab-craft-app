# Sherpa-ONNX Kokoro Neural TTS Integration — Design Specification

**Date:** 2026-10-09  
**Status:** Approved for Implementation Planning  
**Scope:** Integration of `sherpa-onnx` and `onnxruntime` C++ runtime into `SpeechKit` to deliver real on-device neural voice synthesis for Kokoro-82M (Nova, Orion, Sarah, Michael).

---

## 1. Problem Statement & Motivation

During the testing of the Offline AI Pack on physical iOS devices:
1. **Successful Model Download**: The user successfully downloaded the Kokoro-82M model package (~85MB) containing `model.onnx`, `voices.bin`, `tokens.txt`, and `espeak-ng-data`.
2. **Beeping Sound (Tiếng tút tút) Instead of Human Speech**: When previewing voices (Nova, Orion) in the AI Voice Picker Sheet, only sine-wave audio tones ("tiếng tút tút") were produced.
3. **Root Cause**: `KokoroInferenceWorker.swift` defined the protocol `SherpaOnnxOfflineTtsWrapper`, but because `sherpa-onnx` was not linked, `ttsWrapper` defaulted to `nil`, falling back to `synthesizeToneSamples` (a placeholder generating 330Hz / 220Hz sine wave tones).

The goal of this architecture is to link the official **`sherpa-onnx`** C++ runtime (`SherpaOnnxIOS` and `onnxruntime-ios` XCFrameworks) via `SpeechKit` and connect it into `KokoroInferenceWorker`, producing authentic, studio-grade 24kHz human speech on-device.

---

## 2. Architectural Decisions & Selected Approach

### 2.1 Module Seam: `Packages/SpeechKit` Integration
Rather than modifying the complex Xcode project file (`VocabCraftApp.xcodeproj/project.pbxproj`) directly, we encapsulate the C++ dependency inside the local Swift package **`SpeechKit`**:
- `Packages/SpeechKit/Package.swift` adds dependency:
  `.package(url: "https://github.com/k2-fsa/sherpa-onnx", exact: "1.13.8")`
- `SpeechKit` target depends on `.product(name: "sherpa-onnx", package: "sherpa-onnx")` and links the standard C++ library (`.linkedLibrary("c++")`).
- `SpeechKit` is already an `XCLocalSwiftPackageReference` in `VocabCraftApp.xcodeproj`. Consequently, `VocabCraftApp` gains access to `SpeechKit`'s TTS wrappers seamlessly without fragile `.pbxproj` manipulation.

### 2.2 Concrete Wrapper: `SherpaKokoroTTSWrapper`
Inside `Packages/SpeechKit/Sources/SpeechKit/Engine/SherpaKokoroTTSWrapper.swift`:
- Conforms to `Sendable` and manages the underlying C/Swift `SherpaOnnxOfflineTtsWrapper`.
- Configures Kokoro model parameters:
  - `model`: `kokoro/model.onnx`
  - `voices`: `kokoro/voices.bin`
  - `tokens`: `kokoro/tokens.txt`
  - `dataDir`: `kokoro/espeak-ng-data`
  - `lengthScale`: `1.0` (adjusted by speech rate)
  - `noiseScale`: `0.667`
  - `noiseScaleW`: `0.8`
- `generate(text:speakerId:speed:)` returns raw 24kHz `[Float]` samples generated by the ONNX model.
- `unload()` frees the C++ model memory when not in use.

## 5. Memory & Concurrency Governance

1. **Background Actor Execution**: All phonemization (`espeak-ng`) and tensor inference run inside `KokoroInferenceWorker` (a background `actor`), ensuring zero frame drops on `@MainActor`.
2. **Cooperative Cancellation**: Checks `Task.isCancelled` before, during, and after inference. If cancelled, stops audio generation and rethrows `CancellationError`.
3. **Memory Footprint & Lifecycle**:
   - Model is initialized lazily upon first voice preview or conversation start.
   - `unload()` frees ONNX sessions and vector embeddings when leaving roleplay sessions or closing voice settings to free ~80–120MB of RAM.
4. **Safety & Fallbacks**:
   - If model files are not downloaded, throws typed `AIPackError.downloadRequired`.
   - Never falls back to sine wave beeps in production.

1. **Unit & Integration Tests**:
   - `SpeechKitTests`: Verify `SherpaKokoroTTSWrapper` initialization and mock sample generation.
   - `KokoroTTSEngineTests`: Verify voice mapping, 24kHz WAV conversion, and playback delegate lifecycle.
   - `OnDemandAIModelManagerTests`: Verify 4-file integrity checks and auto-flattening.
2. **Compilation & Linting**:
   - Zero compiler warnings under Swift 6 strict concurrency.
   - Zero SwiftLint violations across all files (`swiftlint lint --strict`).
3. **Auditory Verification**:
   - Tapping Play on Nova produces warm, natural female speech (*"Hi, I'm Nova..."*).
   - Tapping Play on Orion produces natural male speech (*"Hello. I'm Orion..."*).
   - Zero sine wave beeps ("tiếng tút tút").
