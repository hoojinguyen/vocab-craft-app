# VocabCraft iOS App & Widget - Technical Design Specification

## 1. Executive Summary

**VocabCraft** is a privacy-first, zero-cost, offline-capable iOS application designed for learning English vocabulary and sentence patterns with a specific focus on **speaking reflex training (luyện phản xạ nói)** and **passive learning via Home Screen/Lock Screen Widgets**.

The system utilizes a pre-built SQLite dataset engine (`english_dataset.db` generated by a Python engine) bundled directly inside the iOS App Bundle, operating at sub-3ms query latency. User progress and Spaced Repetition System (SRS) data are saved in a separate SwiftData store located within an App Group shared container, allowing seamless real-time interaction between the iOS Main App and Interactive iOS 17+ Widgets.

---

## 2. Goals & Key Features

1. **Self-Hosted & $0 Cost Infrastructure:**
   - 100% Offline operation.
   - Bundled read-only dataset `english_dataset.db`.
   - Native Apple AVFoundation (TTS) & Speech Framework (STT) for audio/voice. No third-party API dependencies.

2. **Speaking Reflex Training (Luyện phản xạ nói):**
   - Speed reflex drills displaying Vietnamese prompts with voice audio target timers (~2.5 seconds).
   - Real-time Speech-to-Text (`SFSpeechRecognizer`) for evaluating user speech accuracy and response latency.
   - Native Text-to-Speech (`AVSpeechSynthesizer`) for pronunciation modeling.

3. **Interactive iOS 17+ Widget & Lock Screen Widget:**
   - Home Screen Widgets (Small & Medium) and Lock Screen Widgets.
   - Interactive buttons (`AppIntents`): `[Next Word]` and `[Mark Learned]` right on the Widget without launching the app.
   - Timeline refresh policies (15m / 30m background updates).

4. **Spaced Repetition System (SRS) & User Progress:**
   - Adaptive review intervals based on user accuracy and speaking reflex speed.
   - Offline progress tracking saved in shared SwiftData SQLite store.

5. **Direct Physical Device Deployment:**
   - Tailored for Xcode deployment directly to personal iPhone via personal Apple ID.

## 4. Data Models & Schemas

### 4.1 Read-Only Dataset Schema (`english_dataset.db`)
Extracted from `EnglishDataset` specifications:

- `words`: `id`, `lemma`, `pos`, `ipa_us`, `cefr_level`
- `definitions`: `id`, `word_id`, `definition_en`, `definition_vi`, `example`
- `sentences`: `id`, `text_en`, `text_vi`, `audio_path`, `cefr_level`
- `reflex_drills`: `id`, `sentence_id`, `drill_type`, `prompt_text`, `correct_answer`, `distractors_json`, `target_time_ms`
- `dialogue_nodes`: `id`, `tree_id`, `parent_node_id`, `sentence_id`, `speaker_role`, `choice_label`

### 4.2 Writable User Progress Schema (`user_progress.sqlite` via SwiftData)

```swift
import Foundation
import SwiftData

@Model
final class UserWordProgress {
    @Attribute(.unique) var wordId: Int64
    var masteryLevel: Int // 0 (New) to 5 (Mastered)
    var easeFactor: Double // Default 2.5 for SM-2 algorithm
    var intervalDays: Int
    var nextReviewDate: Date
    var lastReviewDate: Date
    var totalReviews: Int
    var correctCount: Int
    
    init(wordId: Int64) {
        self.wordId = wordId
        self.masteryLevel = 0
        self.easeFactor = 2.5
        self.intervalDays = 1
        self.nextReviewDate = Date()
        self.lastReviewDate = Date()
        self.totalReviews = 0
        self.correctCount = 0
    }
}

@Model
final class ReflexSessionLog {
    var id: UUID
    var drillId: Int64
    var responseTimeMs: Int
    var accuracyScore: Double // 0.0 to 1.0
    var timestamp: Date
    
    init(drillId: Int64, responseTimeMs: Int, accuracyScore: Double) {
        self.id = UUID()
        self.drillId = drillId
        self.responseTimeMs = responseTimeMs
        self.accuracyScore = accuracyScore
        self.timestamp = Date()
    }
}

@Model
final class WidgetCurrentState {
    @Attribute(.unique) var id: String // "default_widget"
    var currentWordId: Int64
    var lastUpdated: Date
    
    init(currentWordId: Int64) {
        self.id = "default_widget"
        self.currentWordId = currentWordId
        self.lastUpdated = Date()
    }
}
```

## 5. Subsystems & Implementation Details

### 5.1 SQLite Dataset Engine (`DatasetEngine.swift`)
- Opens `english_dataset.db` from `Bundle.main` with `SQLITE_OPEN_READONLY | SQLITE_OPEN_FULLMUTEX`.
- Implements high-speed parameterized queries:
  - `getRandomReflexDrill(cefrLevel: String)`
  - `getWordDetails(lemma: String)`
  - `getNextWidgetWordCandidate()`

### 5.2 Audio & Speech Subsystem (`AudioService.swift`)
- **Text-to-Speech (`TextToSpeechService`):**
  - Wraps `AVSpeechSynthesizer` with configured `AVSpeechSynthesisVoice(language: "en-US")`.
  - Rate control (0.48 - 0.52 for natural speaking pace).
- **Speech-to-Text (`SpeechRecognitionService`):**
  - Wraps `SFSpeechRecognizer(locale: Locale(identifier: "en-US"))`.
  - Configures `AVAudioEngine` and `SFSpeechAudioBufferRecognitionRequest`.
  - Performs live string distance / matching against `correct_answer` prompt.

### 5.3 WidgetKit & App Intents (`VocabWidget.swift` & `WidgetIntents.swift`)
- Target: `VocabCraftWidgetExtension`.
- App Group container: `group.com.hoojinguyen.vocabcraft`.
- **AppIntents:**
  - `NextWordIntent`: Fetches next word from `DatasetEngine`, updates `WidgetCurrentState` in SwiftData AppGroup, triggers `WidgetCenter.shared.reloadTimelines(ofKind: "VocabWidget")`.
  - `MarkLearnedIntent`: Updates `UserWordProgress` mastery score and rotates widget word.
- **TimelineProvider:** Generates entries for every 15-30 minutes and handles interactive refresh instantly.
